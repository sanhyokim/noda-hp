## 1. 全体

| 項目 | 内容 |

## 11. 安全（指示書7章のとおり）

- 公開フォルダの `.htaccess` で `app/ storage/ vendor/ migration/` と `composer.*`・`README*` を 403、各フォルダにも「すべて拒否」の `.htaccess`
- `media/` と `wp-content/` では PHP を動かさない
- 管理画面：bcrypt、5回失敗で15分ロック、CSRF、セッションは HttpOnly・Secure・SameSite=Lax
- お問い合わせ：ハニーポット、3秒未満は拒否、同じ IP から1分に3回まで、CSRF、添付は公開領域の外
- AI 相談の受け口は、同じサイトからの送信（独自の見出し `X-Noda-Chat` と Origin）だけ受ける

## 12. 置き方と手直し

- 初回：`tools/build-package.sh` で 90MB ごとの zip（9個）と `install.php`。Boss がファイルマネージャーで上げ、`install.php` を開くと少しずつ広げる（`docs/DEPLOY.md` A）
- 手直し：`tools/build-update.sh <前のコミット>` で、変わったファイルだけの zip（`index.php` は毎回入れる）と `install.php`。**2回目以降は install.php を毎回ちがう名前に変えて開く**（LiteSpeed が一度消えた同じ名前のファイルをしばらく「無い」扱いにするため）。上げたファイルが外から見えるまで数分かかることがある
- 本番切り替え：`docs/DEPLOY.md` B（WordPress のファイルを `public_html` の外へよけ、/new/ の中身を一番上へ移す。戻す手順つき。手元の Apache で切り替えと戻しを試験済み）
