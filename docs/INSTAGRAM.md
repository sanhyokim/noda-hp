# Instagram のつなぎ方（ボス向け）

トップページの「Instagram - 私たちの日々の仕事」に、野田の Instagram（@noda_duct）の最新の投稿6件を自動で出すための手順です。
最初に一度だけ行えば、あとは自動で続きます（6時間ごとに新しい投稿を読み込み、合言葉の期限も自動で延長します）。

つなぐまでの間は、現行サイトの施工写真6枚と「Instagram で見る」ボタンが代わりに出ています。お客様から見て困ることはありません。

所要時間：30分ほど
用意するもの：パソコン、Facebook のアカウント、Instagram（@noda_duct）のログイン情報、Instagram アプリが入ったスマホ

> 画面の名前は、Meta（Facebook・Instagram の会社）が時々変えます。この手順書と少し違う時は、近い名前のボタンを選んでください。分からなくなったら、画面の写真を送ってもらえれば次に押す所をお伝えします。
> 画面が英語の時は、かっこ内の英語の名前を探してください。

---

## 0. 先に確かめること：Instagram が「プロアカウント」になっているか

この仕組みは、Instagram の「プロアカウント」（ビジネスまたはクリエイター）でしか使えません。

1. スマホの Instagram アプリで @noda_duct にログインする
2. 右下のプロフィール → 右上の「≡」→「アカウントの種類とツール」を開く
3. 「プロアカウントに切り替える」と出ていれば、まだ個人用です。押して「ビジネス」を選び、案内どおり進めてください（無料。投稿やフォロワーはそのまま残ります）
4. 「個人用アカウントに切り替える」と出ていれば、もうプロアカウントです。次へ進んでください

## 1. Meta の開発者用ページに登録する（初回だけ）

1. パソコンで https://developers.facebook.com を開き、Facebook のアカウントでログインする
2. 初めての時は「スタート（Get Started）」と出るので、案内どおりに登録する（電話番号かメールの確認があります）

## 2. アプリを作る

ここでいう「アプリ」は、ホームページが Instagram の投稿を読むための通行証のようなものです。お客様に見えるものではありません。

1. 右上の「マイアプリ（My Apps）」→「アプリを作成（Create App）」を押す
2. アプリの名前：`noda-hp`（何でも構いません）、連絡先メール：ボスのメールアドレス を入れて「次へ」
3. 使い方（ユースケース）を聞かれたら「Instagram でメッセージとコンテンツを管理（Manage messaging & content on Instagram）」を選んで「次へ」
4. ビジネスポートフォリオを聞かれたら「今はビジネスポートフォリオをリンクしない」で構いません
5. 最後に「アプリを作成（Create app）」を押す（Facebook のパスワードをもう一度聞かれることがあります）

## 3. Instagram のアカウントをアプリにつなぐ

1. 作ったアプリの画面の左の一覧で「ユースケース（Use cases）」を開き、Instagram の所の「カスタマイズ（Customize）」を押す
2. 「Instagram ログインによる API 設定（API setup with Instagram login）」を開く
3. 「2. アクセストークンを生成（Generate access tokens）」の所で「アカウントを追加（Add account）」を押す
4. Instagram のログイン画面が出るので、@noda_duct でログインする
5. 「許可」の画面が出たら、プロフィールとメディア（投稿）を見ることを許可する
6. 一覧に @noda_duct が出たら、その横の「トークンを生成（Generate token）」を押す
7. 長い英数字（`IG` で始まることが多い）が出ます。「コピー」を押す
   - これが「トークン」です。ホームページが投稿を読むための合言葉なので、他の人には見せないでください

### うまくいかない時：テスターの招待を受ける

手順3でエラーが出たり、アカウントが一覧に出ない時は、次の2つを行ってから手順3をやり直してください。

1. アプリの画面の左の一覧「アプリの役割（App roles）」→「役割（Roles）」→「メンバーを追加（Add People）」→「Instagram テスター（Instagram Tester）」を選び、`noda_duct` を入れて送る
2. スマホの Instagram アプリで「設定」→「アプリとウェブサイト（Apps and websites）」→「テスターへの招待（Tester invites）」を開き、「承認（Accept）」を押す
   - この「承認」を忘れると、トークンが働きません。いちばん多いつまずきです

## 4. 管理ページに貼り付ける

1. 新しいホームページの管理ページ（`/admin/`）にログインする
2. 上の「設定」→「Instagram の表示」の欄を開く
3. 「トークン」の欄に、手順3でコピーした英数字を貼り付ける
4. 「保存して接続を試す」を押す
5. 緑の帯で「Instagram につながりました。最新の投稿を○件読み込み…」と出れば完了です。トップページを開くと、最新の投稿6件に変わっています

赤い帯が出た時は、書かれている内容を確かめてください。よくある原因：

| 出てくる文 | 原因と直し方 |
|---|---|
| トークンの形が正しくありません | コピーした時に前後の空白や別の文字が入った。もう一度コピーして貼り直す |
| Instagram からトークンが受け付けられませんでした | ① 別のアカウントや古いトークンを貼った → 手順3の 6〜7 をやり直す。② テスターの招待を「承認」していない → 上の「うまくいかない時」を行う。③ Instagram がプロアカウントになっていない → 手順0 |
| Instagram につながりませんでした | Instagram 側かサーバーの通信が一時的に止まっている。少し時間をおいて、もう一度「保存して接続を試す」を押す |

## そのあとのこと

- **毎日の作業はありません。** Instagram に投稿すれば、6時間以内にトップページへ出ます
- **トークンの期限（60日）は自動で延長します。** 期限の10日前から、ホームページが自動で新しくします。管理ページの「設定」で期限の日付が見られます
- **長く止まっていた時**（サーバーの引っ越しなどで60日以上読み込みがなかった時）は期限が切れます。その時は手順3の 6〜7 で新しいトークンを出し、手順4で貼り直してください
- **表示をやめたい時**は、管理ページの「設定」→「トークンを消す」を押すと、代わりの写真6枚に戻ります
- Instagram のパスワードを変えても、トークンはそのまま使えます

## 実装の覚え書き（制作側向け）

- 使っているのは Instagram API with Instagram Login（`graph.instagram.com`）。`/me/media` で最新12件を取り、画像・動画のサムネイルから6件を出す（`app/lib/instagram.php`）
- 取得は6時間に1回まで。結果は `storage/cache/instagram.json` に保存し、公開ページはこのファイルだけを読む。取得に失敗した時は前回のファイルを使う
- 長期トークン（60日）は、取得時に残り10日以下なら `refresh_access_token` で延長する
- トークンが無い・無効の時は `ig-fallback-1.jpg`〜`ig-fallback-6.jpg` と「Instagram で見る」ボタン
- 試験：`storage/cache/instagram.json` にダミーの JSON を置くと6枚表示になる（指示書 8章）
