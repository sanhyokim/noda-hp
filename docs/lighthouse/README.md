読み方の注意

- SEO の 92 は、手元の「一番上の robots.txt」が試験用の偽物だったため（本物のサイトでは 100 の見込み）。ベストプラクティスの減点は、測るために付けた見出しで Google Fonts の読み込みが断られたため
- 性能は測るたびに大きくぶれる（同じトップで 56〜77）。この作業環境から Google Fonts へは中継を通るため
- 性能の目標（90）には届いていない。主な原因は2つ：
  1. トップの最初の画面の、横に流れる施工写真（3段。表示の後に JS で写真を付けるため、LCP が遅れる）
  2. 日本語の Web フォント（Noto Sans JP の4つの太さ）。読み込むたびに文字の組み直しが起き、TBT になる。日本語フォントを読まない試験ではトップが 91 になった
- 本番に切り替えた後に、https://pagespeed.web.dev/ で本物のサーバーで測り直し、必要なら上の2点を調整する（見た目に関わるため、Boss と相談のうえ）

## 2026-10-23 の見直し（本物のサーバーの /new/ で測定）

- 手直し前の /new/：トップ 43〜76、施工事例一覧 82（同じ計測でもぶれる）。一番の原因は日本語の Web フォントの組み直し（Style & Layout 約2.8秒）
- 手直し：Noto Sans JP は幅 1024px 以上だけで読み、スマホは端末の日本語フォント（iPhone はヒラギノ、Android は Noto Sans CJK）で表示。Barlow Condensed（英数字）はどちらでも読む。ロゴに 720px の webp、20周年マークの webp を軽く
- 手元（圧縮あり）での結果：トップ 92、施工事例一覧 96、詳しいページ 98、煙・臭い 95、流れ 96、会社概要 99（TBT はほぼ 0）
