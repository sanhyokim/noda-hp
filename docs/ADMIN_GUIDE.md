# 管理画面の使い方（ボス向け）

新しいホームページの施工事例・お知らせは、この管理画面から書きます。パソコンでもスマホでも、同じ画面・同じ手順で使えます。

| | 本番に切り替える前 | 本番に切り替えた後 |
|---|---|---|
| 管理画面 | https://duct-noda.com/new/admin/ | https://duct-noda.com/admin/ |
| ホームページ | https://duct-noda.com/new/ | https://duct-noda.com/ |

> スマホでは、管理画面を開いたら共有メニューの「ホーム画面に追加」をしておくと、次からアプリのように1回で開けます。

---

## 1. ログイン

1. 上の表の「管理画面」を開く
2. 最初の設定で決めた ID とパスワードを入れて「ログイン」
   - 5回続けて間違えると、15分間ログインできなくなります（なりすまし防止）。15分待てば元に戻ります
   - パスワードを忘れた時は、制作側に連絡してください（画面からは作り直せません）
3. 使い終わったら、右上の「ログアウト」（扉のマーク）を押す。会社の共用パソコンでは必ず押してください

画面の上に「施工事例」「お知らせ」「カテゴリ」「設定」の4つの入口があります。

---

## 2. 施工事例を新しく書く

1. 「施工事例」→「新しく書く」
2. 次の欄を入れる

| 欄 | 書くこと |
|---|---|
| 題名（必須） | 一覧やトップに出る見出し。例：「平尾の人気店に消煙機を設置しました！」 |
| 本文 | 工事の内容。上の「見出し」「箇条書き」「リンク」のボタンで形を整えられます。Word などからの貼り付けもできます（余計な飾りは自動で外れます） |
| 写真 | 3. を見てください |
| 業態（公開する時は1つ以上） | お店の種類。施工事例の絞り込みと「関連する施工事例」に使います |
| 工事の種類（公開する時は1つ以上） | 行った工事。当てはまるものを全部 |
| 状態 | 「公開する」か「下書き」 |
| 投稿日 | ふつうは今日のまま。4. も見てください |
| 場所（任意） | 例：福岡市博多区。一覧のカードに出ます |
| 検索結果に出る題名・説明文・ページのアドレス（任意） | 空のままで大丈夫です。自動で作ります |

3. いちばん下の「保存する」を押す。「保存しました」と出れば完了です

**題名に「消煙機」「無煙ロースター」などの言葉を入れると**、サービスのページの「関連する施工事例」で先に出ます。

---

## 3. 写真

- 「写真を選ぶ」を押して選ぶ（何枚でも、まとめて選べます）。パソコンでは、写真をこの枠にドラッグしても追加できます
- 1枚15MBまで。大きな写真やスマホの写真（iPhone の HEIC も）は、自動で縮めてから送るので、そのまま選んで大丈夫です
- **並べ替え**：写真の左上の「⠿」をつまんで動かす。スマホでは写真の下の「←」「→」でも動かせます
- **代表の写真**：「代表にする」を押した写真が、一覧・トップ・関連事例のカードに出ます。何もしなければ1枚目が代表です
- **外す**：写真の下の「×」
- 写真は横長（4:3 か 3:2）がきれいに並びます。縦長の写真も使えますが、カードでは上下が少し切れます

---

## 4. 下書き・確認・予約投稿

- **保存して確認**：下書きのままでも、公開した時と同じ見た目で確かめられます。上の「編集に戻る」で戻ります
- **下書き**：「状態」を「下書き」にして保存すると、ホームページには出ません
- **予約投稿**：「投稿日」を明日以降にして「公開する」で保存すると、その日になった時に自動でホームページに出ます。一覧では「予約」の印が付きます
- **並び順**：一覧やトップは、投稿日の新しい順です。過去の工事をあとから載せる時は、投稿日を工事の日にすると、その位置に並びます

---

## 5. 直す・削除する

- 「施工事例」の一覧で題名を押すと、編集の画面になります。直して「保存する」
- 一覧の上の「題名で探す」で、例えば「焼肉」と入れて探せます
- 削除は、編集画面のいちばん下の「削除する」。確認が出ます。**削除すると元に戻せません**。迷う時は「下書き」にしておけば、ホームページからは消えます

---

## 6. スマホから投稿する

手順はパソコンと同じです。現場で撮ってすぐ載せる時の流れ：

1. 管理画面を開き「施工事例」→「新しく書く」
2. 題名と本文を入れる（本文は短くても大丈夫です。あとでパソコンから書き足せます）
3. 「写真を選ぶ」→ 写真のアプリから選ぶ（その場で撮ることもできます）
4. 業態・工事の種類に印を付ける
5. まず「下書き」で保存し、「保存して確認」で見た目を確かめてから「公開する」で保存し直すと安心です

電波の弱い所では写真の読み込みに時間がかかります。「読み込んでいます…」の間は画面を閉じないでください。

---

## 7. お知らせ

「お知らせ」は、施工事例以外の知らせ（年末年始の休み、新しい製品、受賞など）を書く所です。書き方は施工事例と同じで、写真・業態の欄がないだけです。
トップの「お知らせ」欄には、施工事例とお知らせが混ざって新しい順に5件出ます。

---

## 8. カテゴリ（業態・工事の種類）

施工事例の絞り込みに使う名前の一覧です。

- **名前を変える**：名前を直して「名前を保存」。その名前が付いた事例すべてに反映されます
- **並び順**：「↑」「↓」。ホームページの絞り込みのボタンの順番になります
- **追加**：いちばん下の欄に新しい名前を入れて「追加」
- **削除**：「×」。その名前を使っている施工事例が1件でもあると削除できません（先に各事例のカテゴリを変えてください）

---

## 9. 設定

| 項目 | できること |
|---|---|
| お問い合わせの受信一覧 | フォームから届いた内容をすべて見られます。メールが届かなかった時も、ここには残ります |
| AI 相談（チャット） | 今月の会話の数・費用の目安・「役に立ったか」の答え、会話の記録（相談番号や言葉で探せます）、止める・再開する、担当者への知らせの送り方、API キーとモデルの設定（OpenRouter のキーは https://openrouter.ai/keys で作ります。空欄のモデルは anthropic/claude-sonnet-5.5）。モデルを替えたら、ホームページの「AIに相談」で何回か質問して答え方を確かめてください |
| Instagram の表示 | トップの Instagram 欄に最新6件を出すための設定。手順は別紙「Instagram のつなぎ方」（INSTAGRAM.md） |
| パスワードの変更 | 今のパスワードと新しいパスワード（10文字以上）を入れて変更 |
| データの書き出し | 施工事例・お知らせ・カテゴリを1つのファイルに保存します。年に1回ほど、控えとして保存しておくと安心です |

### AI 相談から届くもの

| 届くもの | いつ | 中身 |
|---|---|---|
| 「【野田公式HPからの折り返し依頼】」のメール | お客様が「電話をもらう」で名前と電話番号を送った時、すぐ | お名前・電話番号・都道府県・都合のよい時間帯・それまでの会話・相談番号。受信一覧にも残ります。**お客様は電話を待っているので、早めにお電話してください** |
| 「【野田公式HP】AI相談のまとめ」のメール | 毎朝9時ごろ（前の日に相談があった時だけ） | 前の日の相談ぜんぶ：相談番号・始めたページ・質問と答え・その後の動き。送り方は「設定」→「AI 相談」で変えられます |
| LINE のメッセージ | お客様が「LINEで写真を送る」を押した時 | 「【HPのAI相談から】相談番号 ○○○○○○」と質問が入っています。「設定」→「会話の記録を見る」で相談番号を入れると、AI とのやり取りが見られます |

最後のやり取りから30分たった相談は、「終わった相談」として扱います。

---

## 10. 固定のページ（会社概要・サービスなど）の写真や文章を替えたい時

施工事例・お知らせ以外のページ（トップの大きな写真、サービスの説明、会社概要など）は、管理画面からは変えられません。

- **おすすめ**：替えたい写真や文章を制作側に送ってください。直したファイルだけの小さな zip でお渡しします（入れ方は DEPLOY.md の「8. 手直しを入れる時」）
- **自分で写真だけ替える場合**（同じ形の写真に替える時だけ）：
  1. ファイルマネージャーで `assets/img` を開き、替えたい写真の名前を確かめる（例：`flow-check.jpg`）
  2. 新しい写真の名前をそれと **まったく同じ** にして上げ、上書きする（縦横の比率も元と同じにしてください。違うと、はみ出したり余白が出たりします）
  3. 同じ名前で `.webp` の付いたファイル（例：`flow-check.webp`）があれば、**削除する**（残っていると、古い写真が出続けます）
  4. ホームページで、写真が替わったか確かめる

## 困った時

| こんな時 | 原因と直し方 |
|---|---|
| 「保存できませんでした」と赤く出る | 赤い印の欄を直してもう一度。題名は必ず、公開する時は業態と工事の種類も1つ以上必要です |
| 写真が「読み込めませんでした」 | 写真以外のファイルか、15MB を超えています。スマホのスクリーンショットなど別の形の写真で試してください |
| 保存したのにホームページに出ない | 「状態」が下書き、または投稿日が未来（予約）になっていないか確かめてください |
| 「画面の有効期限が切れました」 | 長い時間開いたままだと出ます。ページを読み込み直してから入れ直してください。長い本文を書く時は、途中で「下書き」で保存しておくと安心です |
| ログインできない | 5回間違えると15分ロックされます。パスワードを忘れた時は制作側に連絡してください |
| 画面がおかしい・エラーが出る | 画面の写真を制作側に送ってください |
